# get-access-tokens-without-template
Tutorial for getting an access token for apps not using the Shopify app template library.

**Tutorial:** [Get access tokens without the template](https://shopify.dev/docs/apps/build/authentication-authorization/get-access-tokens-manually)

## Languages

- `node/` — Node.js example
- `curl/` — cURL/Bash example

## Usage

1. Copy `.env.example` to `.env` and add your Client ID, Client Secret, and store subdomain
2. Install dependencies and start the server
3. Open the app in your dev store — the example shows how to call shopify.idToken() from the frontend, pass it to the backend, and exchange it for an access token
